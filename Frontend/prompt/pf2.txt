IMPORTANT UI CORRECTION:

The current UI is incorrectly designed as a fixed mobile-phone-sized application centered inside the desktop browser.

I DO NOT WANT A PHONE MOCKUP.

I want a REAL RESPONSIVE WEBSITE.

The Figma screenshots are only the visual reference. They should NOT be interpreted as "render the entire application inside an iPhone frame."

==================================================
DESKTOP REQUIREMENT
==================================================

On desktop/laptop screens:

- The application must use the available browser width.
- Do NOT render the website inside a 390px / 430px phone container.
- Do NOT show an artificial phone frame.
- Do NOT use iPhone borders, notch, or phone-like outer container.
- Do NOT center the entire application inside a narrow mobile-width box.

Create a proper desktop web layout.

Use:

width: 100%;
min-height: 100vh;

Create a responsive max-width content container where appropriate.

For desktop:

- Header/navigation should span the page.
- Main content should have a proper desktop width.
- Content can use 2-column layouts where appropriate.
- Cards should expand naturally.
- Form sections should use the available width.
- Maintain the Nuzio AI dark/purple visual identity from the Figma.

==================================================

Desktop layout:

==================================================
MOBILE REQUIREMENT
==================================================

On mobile devices:

Automatically switch to a single-column layout.

The website should fit the device width.

No horizontal scrolling.

No fixed desktop widths.

No phone frame.

The content should naturally become:

width: 100%;
padding: 16px;

Profession chips should wrap.

Interest chips should wrap.

Voice cards should become full-width.

Buttons should become touch-friendly.

Typography should scale down appropriately.

==================================================
BREAKPOINTS
==================================================

Use responsive breakpoints.

Recommended:

Mobile:
< 640px

Tablet:
640px - 1024px

Desktop:
>= 1024px

Large desktop:
>= 1280px

Do not write CSS specifically for one device model.

Use flexible layouts such as:

display: grid;
grid-template-columns: repeat(auto-fit, minmax(...));

and:

display: flex;
flex-wrap: wrap;

Use max-width only for readable content sections, not for the entire application.
