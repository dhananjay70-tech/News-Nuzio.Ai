==================================================
AUTHENTICATION
==================================================

The Figma login screen contains:

"Continue with Google"

Implement Google authentication.

Recommended flow:

Frontend obtains Google credential.

Frontend sends:

POST /api/auth/google

Request:

{
  "credential": "GOOGLE_ID_TOKEN"
}

Backend:

1. Verify Google ID token.
2. Extract:
   - googleId
   - email
   - name
   - picture
3. Find user by googleId/email.
4. Create user if not found.
5. Generate JWT.
6. Return JWT and user.

Response:

{
  "success": true,
  "token": "...",
  "user": {
    "id": "...",
    "name": "...",
    "email": "...",
    "avatarUrl": "..."
  }
}

Use a server-side Google OAuth/client configuration.

Never expose Google client secrets in frontend code.

==================================================
JWT
==================================================

Create:

Authorization:

Bearer <JWT>

Middleware:

requireAuth

It should:

1. Read Authorization header.
2. Validate Bearer token.
3. Verify JWT.
4. Attach userId to req.user.
5. Continue request.

If invalid:

401 Unauthorized
